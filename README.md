A faster drop-in for makefun-diff 1.0.0: an exact Myers line diff that answers byte-identically on every case. One Map pass interns both texts' lines to ids, the greedy search runs on integers in a single triangular trace (one load and one store per diagonal step, deletion winning ties, no edge pruning), and the patch is emitted as pieces joined once.

## Run it

```sh
node main.ts
```

The harness runs `node main.ts`; it reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
